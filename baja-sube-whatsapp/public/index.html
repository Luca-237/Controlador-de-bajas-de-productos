El bot lee los mensajes con el WhatsApp de un teléfono que está dentro del grupo, vinculado como dispositivo (igual que WhatsApp Web). Por eso el número no se escribe acá: es el del teléfono que escaneó el código QR.

Vincular WhatsApp

  1. Abrí WhatsApp en un teléfono que esté dentro del grupo.
  2. Tocá Dispositivos vinculados → Vincular un dispositivo.
  3. Escaneá este código. Se renueva solo cada 20 segundos: si no lo toma, esperá el siguiente.

Cómo cambiar el número
  1. Sumá el teléfono nuevo al grupo (tiene que ser participante).
  2. En el teléfono vinculado ahora: WhatsApp → Dispositivos vinculados → tocá este bot → Cerrar sesión.
  3. El bot borra la sesión vieja solo y en esta pantalla aparece un código QR nuevo.
  4. Escanealo con el teléfono nuevo. Este panel pasa a mostrar el número nuevo.

Ejemplo de cómo se ve: +54 9 353 412-3456 (Villa María). Usá un chip de la empresa: nunca un número personal ni el WhatsApp Business de atención a clientes.

Grupo que se escucha

Se busca el grupo cuyo nombre contenga este texto, sin importar mayúsculas, acentos ni emojis. Ejemplos: Código que no hay más encuentra “⚠️ CODIGO QUE NO HAY MAS”; bajas deposito encuentra “Bajas Depósito Central”.

Es el identificador interno del grupo: no cambia aunque le cambien el nombre. Si está cargado, manda el JID y el nombre se ignora. Formatos válidos: 120363025246125486@g.us o 5493534123456-1609459200@g.us (grupos viejos). Al elegir un grupo de la lista se completa solo.

El bot toma el cambio solo, en menos de 30 segundos. Ojo: si elegís otro grupo, deja de leer el anterior.
